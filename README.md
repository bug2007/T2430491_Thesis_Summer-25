The titel of the thesis is "A Sentiment-Based Comprehensive Rating Model with Extensive Dataset for Nationwide Hospital Rating in Bangladesh Using Natural language Processing and Machine Learning."  
We have created a nationwide dataset of patient reviews for hospitals in Bangladesh, utilizing information available on the Google Star Rating platform. Our goal is to develop an aspect-basedhospital ranking
system for Bangladesh, enabling individuals to make informed decisions about which hospital is best suited for their treatment, surgery, or diagnostic needs.
